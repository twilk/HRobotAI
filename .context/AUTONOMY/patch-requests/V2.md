# Patch requests — V2

## 1. `docker-compose.yml` — dodac usluge `stt` (stt-service)

PLIK: `docker-compose.yml`

MIEJSCE: nowa usluga na poziomie `services:`, obok `agent-service` (sasiedztwo logiczne — oba to
uslugi Pythonowe w module Agent Glosowy/HR). Dopisac tez wolumen `stt_models` w sekcji `volumes:`
najwyzszego poziomu.

WSTAW:

```yaml
  stt:
    build:
      context: ./stt-service
      dockerfile: Dockerfile
    image: hrobot/stt-service:latest
    restart: unless-stopped
    networks:
      - default
    ports:
      - "8011:8010"
    environment:
      KEYCLOAK_URL: http://keycloak:8080
      STT_MODEL_SIZE: small
      STT_COMPUTE_TYPE: int8
      STT_LANGUAGE: pl
    volumes:
      - stt_models:/models
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8010/health', timeout=3)"]
      interval: 15s
      timeout: 5s
      retries: 5
      start_period: 20s
```

W sekcji `volumes:` (top-level, obok istniejacych named volumes):

```yaml
  stt_models:
```

DLACZEGO:
- To jest JEDYNY powod, dla ktorego rozpoznawanie mowy w demie nie dziala dzis: `stt-service`
  (kod gotowy, testy zielone, `README.md` w `stt-service/` dokumentuje kontrakt) powstal w nocy i
  nigdy nie trafil do `docker-compose.yml`. Bez tego wpisu web-kit zawsze dostaje
  "Usluga rozpoznawania mowy jest niedostepna" (proxy `STT_SERVICE_URL` nie ma dokad sie odpiac).
- Port hosta **8011**, NIE 8010 — 8010 jest juz zajety przez `agent-service` w tym samym compose.
  Port kontenera zostaje 8010 (tak jest w `Dockerfile`/`README.md` stt-service, nie zmieniam kodu
  serwisu).
- Wolumen `stt_models:/models` jest obowiazkowy: bez niego kazdy `docker compose up`/restart
  serwisu odswieza `~490 MB` modelu `faster-whisper small` z Hugging Face Hub od zera (patrz
  `ENV HF_HOME=/models` w `stt-service/Dockerfile`). Zweryfikowane recznie ponizej.
- Healthcheck bije w `GET /health` (bez auth — patrz `stt-service/app/main.py`), tak samo jak
  wzorzec dla `agent-service`.

DOWOD (recznie, poza compose, port hosta 8020 zeby nie kolidowac z docelowym 8011 ani z 8010
agent-service):
